# How do you get your containers into a server?
Development for your application/containers is being done on your personal machine, so how do you get it into a server? You can log into the server (either through SSH or Remote Desktop Connection if your kernel has a Desktop GUI) and git clone your repository. You'd then just have to create your .env file and can run your docker compose file.

Relying on the terminal to montior the containers is doable, but not ideal (ie `docker ps` to list running containers or `docker logs <container name>` to view the logs). An easier alternative is a service called `Portainer`.

# What is Portainer
Portainer is a web based GUI platform that allows you to configure, monitor, and deployed containerized applications. It acts as a visual dahsboard for all your containers, similar to Docker Desktop on your personal PC. It allows you to see all your stacks, containers, environments/secrets, images, networks, and volumes all in one place. You also have the ability to set up alerts, which can send notifications if a container crashes or goes down.
