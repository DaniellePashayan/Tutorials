# Python Tutorials

A collection of hands-on tutorials for learning Python, automation, integrations, and development tools.

## Tutorials

| Tutorial | Description | Level |
|----------|-------------|-------|
| API Databases | Working with APIs, HTTP requests, and databases | Intermediate |
| API Tests Poe | More advanced APIs, test development, and POE | Intermediate |
| ETL Pipelines | Extract, Transform, Load architecture | Intermediate |
| Docker | Using and creating containers | Advanced |

## Getting Started

1. Clone this repository.
2. Open the tutorial directory you want to complete.
3. Follow the instructions in that directory's README.
4. Install the dependencies listed for that tutorial.

Each tutorial is designed to be completed independently.
