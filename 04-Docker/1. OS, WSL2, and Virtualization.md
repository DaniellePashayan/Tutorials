# Operating Systems, WSL2, and Virtualization

# Operating Systems
## What is an operating system?
An operating system (OS) is the core software that manages a computer's hardware and software resources, acting as an intermediary between users/applications and the physical components. Without an OS, you cannot run programs or use a computer.

### Types of Operating Systems
1. Desktop - Windows, MacOS, Linux, ChromeOS
2. Mobile - Android, iOS / iPadOS
3. Server/Cloud - Linux, Windows, UNIX/BSD

In production environments, Linux is the primary operating system used. It combines stability, cost savings, and deep control over hardware and software. 

Unlike windows, Linux servers can run for years without ever needing to be rebooted and their modular structure allows for individuals pieces to be upgraded or restarting without crashing the entire system.

Since Linux is open source, it eliminates the need for licensure. It is also the foundational language of modern cloud infrastructure (like AWS, Microsoft Azure, and Google Cloud). It is also extremely lightweight and users can strip awau unused components to maintain a small digital footprint.

# WSL2
## What is WSL2?
WSL2 is a Microsoft feature that lets you run Linux from within Windows. It creates a small virtual machine within your Windows computer containing a full Linux kernel. This allows you to essentially use Linux with your windows devices. However, on your work laptops, virtualization (ie the ability to create the Linux VM) is disabled. However, on your non-work related devices, this is an option.

# What is Virtualization?
Virtualization is a technology that creates an abstraction layer over the physical hardware, allowing a single physical device to run one or more simulated environments. Each virtual machine (VM) acts as its own independent computer with its own OS, memory, storage, CPU, and file structure. However, the VM shares the underlying hardware resources of the host.

A good example of virtualization is Northwell's "MyNorthwellApps". You've likely heard systems/IT folks refer to it as Northwell's "VDI" (desktop virtualization). MyNorthwellApps uses a type of virtualization that creates a VM for each user. What makes this so secure is that the VDI cannot ever access the operating systems's files, making it extremely safe. This is why you cannot download files from VDI and save locally to your C: drive. 

Athena IDX is also run as a VDI now after the original Indigo update, which is why you cannot download queries to your local machine. If you ever explored the "Save As" screen, you may have noticed that folders you favorited will clear out and why when you save to the "Desktop", it doesn't save to your PC's actual desktop. It saves to the VDI's desktop, which has a completely different file system that your PC cannot access.
